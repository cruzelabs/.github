# Security

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Report it through the process on [cruzemaps.com/security](https://cruzemaps.com/security). Include what you found, how to reproduce it and what an attacker could do with it. We will confirm receipt and keep you updated while we work on a fix.

## Scope

cruzemaps.com and its subdomains, and the code in this organization's repositories.

## What we ask

- Give us reasonable time to fix a problem before you disclose it.
- Do not access, change or delete data that is not yours.
- Do not run tests that degrade the service for others.
